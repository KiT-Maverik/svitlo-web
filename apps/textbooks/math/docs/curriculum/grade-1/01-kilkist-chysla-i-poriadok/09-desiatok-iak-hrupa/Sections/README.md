# Сценарій: Десяток як група

> Educational Screenwriter — чернетка взаємодії. [Методичний brief](../README.md) не змінено.

## Секції

01. [Десять окремих предметів](./01-desiat-okremykh-predmetiv.md) — Відчути десяток як кількість десяти одиниць.
02. [Зв’язуємо десяток](./02-zviazuiemo-desiatok.md) — Зрозуміти об’єднання десяти одиниць в одну групу без зміни кількості.
03. [Розв’язати й перевірити](./03-rozviazaty-i-pereviryty.md) — Показати зворотність групування та сталість кількості.
04. [Дев’ять, десять чи одинадцять](./04-deviat-desiat-chy-odynadtsiat.md) — Знайти точну межу групування в десяток.
05. [Десяток та ще кілька](./05-desiatok-ta-shche-kilka.md) — Побачити кількості 12, 15, 18 як десяток плюс окремі одиниці без формального розрядного запису.
06. [Підсумок: один десяток](./06-pidsumok-odyn-desiatok.md) — Узагальнити групування, розгрупування й незмінність кількості.

## Принципи

Пучок означає **десять одиниць**, а не «один предмет замість десяти». Групування не змінює кількості. Дії учня керовані, без таймера. Плани графіки, аудіо, плашок — лише сценарні вимоги, не імплементація. Формальні розрядні алгоритми не вводяться. Відео не потрібне; практика не є оцінюванням mastery.

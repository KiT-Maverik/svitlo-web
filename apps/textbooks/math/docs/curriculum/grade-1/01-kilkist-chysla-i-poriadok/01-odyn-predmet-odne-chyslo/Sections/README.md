# Сценарій уроку «Один предмет — одне число»

> **Статус:** storyboard draft, не реалізація. Методична специфікація збережена в [README уроку](../README.md).

## Послідовність

01. [Навіщо рахувати?](./01-navishcho-rakhuvaty.md) — Викликати природне запитання про кількість, не влаштовуючи вступного тесту.
02. [Кожен предмет — один рахунок](./02-kozhen-predmet-odyn-rakhunok.md) — Сформувати відповідність «один об’єкт — одне назване число».
03. [Скільки всього?](./03-skilky-vsoho.md) — Усвідомити, що останнє числове слово — кількість *усієї* групи, не тільки останнього яблука.
04. [Інший порядок — та сама кількість](./04-inshyi-poriadok-ta-sama-kilkist.md) — Показати незалежність кількості від розміщення предметів та порядку лічби.
05. [Спробуй порахувати сам](./05-sprobui-polichyty-sam.md) — Перенести принцип на нові множини без попередньої підказки «скільки».
06. [Підсумок: скільки — це вся група](./06-pidsumok-skilky-tse-vsia-hrupa.md) — Завершити трьома принципами: кожен один раз, останнє слово — кількість, перестановка не змінює кількість.

## Загальні режисерські принципи

- Мета — дослідити лічбу через вибір реальних предметів, а не механічне натискання тестових варіантів.
- Жоден крок не вимагає знання графічних цифр: вони вивчатимуться на наступному уроці; картки кількостей використовують крапки та озвучення.
- Учень керує темпом. Текст доступний без звуку, аудіо повторюється; натискання/клавіатура замінюють жести; reduced motion не змінює смисл.
- Всі медіа й елементи UI тут **концептуально запропоновані**, файли не створено. Відео не планується; практична демонстрація інтерактивна.
- Реакції в секціях — тренувальний зворотний зв'язок, не оцінювання навичок або виставлення балів. Assessment Architect визначатиме діагностичні задачі окремо.
- Репліки, альтернативні описи й аудіо потребуватимуть локалізації, сценарій не прив’язаний до країни чи валюти.

## Потрібні ресурси (план)

Ілюстрації яблук, мушель, блоків, картки з моделями кількостей, стани «враховано», текст/озвучення числових слів 1–7. Жодних медіафайлів наразі немає.

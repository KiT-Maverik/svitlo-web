## Режисерські зауваги

У піктограмах має бути **явна легенда**, зокрема «1 значок = 1 предмет/вибір». Порожня категорія має значення 0, а не приховані чи відсутні дані. Таблиця й піктограма однієї вибірки мусять показувати ті самі частоти.

Відео не потрібне: сцени пропонують дослідницькі взаємодії. Ілюстрації й аудіо — лише вимоги до ресурсів; формальна перевірка Skill потребує окремої специфікації. Усі тексти й альтернативні описи локалізуються.

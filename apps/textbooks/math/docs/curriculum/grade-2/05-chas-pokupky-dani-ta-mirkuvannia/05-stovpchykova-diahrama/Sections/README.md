# Сценарій уроку «Стовпчикова діаграма»

## Послідовність

01. [Від таблиці до стовпчиків](./01-concept.md) — Учень заповнює три стовпчики до значень 4,2,5.
02. [Однаковий крок шкали](./02-example.md) — Учень підсвічує інтервали, потім знаходить висоту стовпчика 5.
03. [Чого найбільше?](./03-model.md) — Учень обирає сливи 5, потім груші 2 як найменші.
04. [На скільки більше?](./04-practice.md) — Учень знаходить різницю висот 3, бачить додаткові три сегменти.
05. [Побудуй нову діаграму](./05-transfer.md) — Учень встановлює висоти 3,6,4 та перевіряє таблицею.
06. [Підсумок діаграми](./06-summary.md) — Учень визначає середній за кількістю стовпчик 3 та називає значення.

## Режисерські принципи

Математичний зміст усіх даних зберігається при переході між моделями. Часові шкали та стрілки годинника мають коректні положення, категорії в таблицях і діаграмах мають спільну шкалу, імовірність формулюється без удаваної гарантії. Гроші показано через **умовну валюту «од.»** — не чинні номінали жодної країни. Це сценарії для редакційного рев’ю, без готових компонентів, медіа чи тестів.

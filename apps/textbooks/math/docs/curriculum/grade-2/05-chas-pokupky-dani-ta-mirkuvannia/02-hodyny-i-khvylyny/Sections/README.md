# Сценарій уроку «Години й хвилини»

> Educational Screenwriter · draft. Навчальні цілі й Skill ID зберігаються в [методичній картці](../README.md); повний Learning Brief ще не написано.

## Послідовність

01. [Повна година — 60 хвилин](./01-concept.md) — Учень проходить 12 п’ятихвилинних кроків і читає 60 хв.
02. [Пів години — 30 хвилин](./02-example.md) — Учень обирає 30 хв для половини оберту, 15 для чверті.
03. [Одна година двадцять хвилин](./03-model.md) — Учень з’єднує 60+20 і отримує 80 хв.
04. [Дев’яносто хвилин](./04-practice.md) — Учень знаходить повну годину й залишок, складає «1 год 30 хв».
05. [Обери правильну одиницю](./05-transfer.md) — Учень підбирає хвилини/години для двох навчальних подій, не змушуючи оцінювати секунди як ціль уроку.
06. [Підсумок перетворень](./06-summary.md) — Учень складає 120 хв, 1 год 15 хв, 70 хв.

## Режисерські принципи

Математичний зміст усіх даних зберігається при переході між моделями. Часові шкали та стрілки годинника мають коректні положення, категорії в таблицях і діаграмах мають спільну шкалу, імовірність формулюється без удаваної гарантії. Гроші показано через **умовну валюту «од.»** — не чинні номінали жодної країни. Це сценарії для редакційного рев’ю, без готових компонентів, медіа чи тестів.

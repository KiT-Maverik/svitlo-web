## Секції

01. [Поділи дванадцять на трьох](./01-concept.md) — Учень роздає печива по одному циклічно, отримує по 4.
02. [Скільки груп по чотири?](./02-example.md) — Учень формує 3 групи по 4; відповідає «три групи».
03. [Одна кількість — два запитання](./03-model.md) — Учень обирає, яку величину треба знайти, не лише числову відповідь.
04. [Не завжди без залишку](./04-practice.md) — Учень розкладає 3+3+3, бачить залишок 1; формального алгоритму ділення із залишком не вводити.
05. [Рівні групи та множення](./05-transfer.md) — Учень порівнює сценарій об’єднання й розподілу.
06. [Підсумок двох видів поділу](./06-summary.md) — Учень зіставляє відповіді 3 в групі й 3 групи, але з різним змістом.

## Режисерські принципи

Математичний сенс кожної дії має бути видимим: **кількість груп × кількість у групі** або два різні види ділення (розподіл порівну / утворення груп заданого розміру). Не ототожнювати групи з окремими предметами. Ділення на нуль не дозволене, нульове ділене можливе при ненульовому дільнику. Усе є сценарним draft; медіа та реалізації немає.

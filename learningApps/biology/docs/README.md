# Biology editorial documents

The [Biology Skills Taxonomy](skills/taxonomy.md) is an **unapproved editorial draft** containing 11 proposed Domains, 24 Groups and 115 candidate Skills, with a [separate editorial review](skills/editorial-review.md) covering proposals, editor feedback and open decisions. The document belongs in this textbook package as the durable source of the proposal.

No per-entity Definition documents are expected: the taxonomy itself is the canonical pedagogical source. Taxonomy code, UUIDs, curricula and lessons have **not** been created. Review and approve the taxonomy structure and atomicity before progressing to the next workflow.

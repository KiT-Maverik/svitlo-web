# Biology — Svitlo standalone textbook

Minimal Next.js App Router application scaffold for `@svitlo/biology` in `learningApps/*`.

## Commands

Install workspace dependencies from the monorepo root with `npm ci`, then run:

- `npm run dev --workspace @svitlo/biology`
- `npm run typecheck --workspace @svitlo/biology`
- `npm run lint --workspace @svitlo/biology`
- `npm run build --workspace @svitlo/biology`

This PR initializes the application and shared SkillDomain ownership support. The Biology subject taxonomy, editorial review history and future lesson planning remain in a separate documentation PR.

# Українська мова — Skills Taxonomy

Date: 2026-10-29

Початковий редакційний каталог компетентностей окремого підручника української мови. Перший добір орієнтується на матеріал, з якого можна формувати навчальні програми 1–3 класів: усне мовлення, звукову систему, абетку, читання, письмо, медіакомунікацію, лексику, будову слова, граматику й правопис. Ця таксономія **не призначає навичок конкретним класам і не встановлює верхньої межі глибини їх опанування**; добір, послідовність, педагогічну глибину та вимоги до результатів визначатиме Curriculum.

Межі першої редакції: практична сучасна українська літературна мова та базова грамотність. Поза нею — окрема літературознавча інтерпретація творів (підручник «Мова та література»), історія мови, порівняльна лінгвістика й спеціалізована стилістика. Збіги компетентностей між різними підручниками допустимі, бо кожен має власні локальні Skill-ідентичності.

Орієнтири для перевірки охоплення: [програми МОН для 1–4 класів](https://mon.gov.ua/osvita-2/zagalna-serednya-osvita/osvitni-programi/navchalni-programi-dlya-1-4-klasiv); [оновлений Державний стандарт початкової освіти, затверджений 26 грудня 2025 року](https://mon.gov.ua/news/uriad-zatverdyv-onovlenyi-derzhavnyi-standart-pochatkovoi-osvity-shcho-same-zminiuietsia); [Типова освітня програма, застосування якої для першокласників починається 1 вересня 2028 року](https://mon.gov.ua/news/zatverdzheno-typovu-osvitniu-prohramu-dlia-14-klasiv); [чинний стандарт державної мови «Український правопис», що набрав чинності 28 березня 2026 року](https://mova.gov.ua/news/ukrainskyi-pravopys-iak-standart-derzhavnoi-movy-nabrav-chynnosti). Їх використано для перевірки предметної широти й мовної нормативності, а не для копіювання переліку уроків або призначення класів.

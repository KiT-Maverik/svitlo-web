## Секції

01. [Три кошики по чотири](./01-concept.md) — Учень окремо рахує чотири в першому кошику, потім активує три кошики.
02. [Додаємо однакові групи](./02-example.md) — Учень відкриває групи по черзі, бачить підсумки 4,8,12.
03. [Знайомимося зі знаком ×](./03-model.md) — Учень зіставляє 3×4 із 4+4+4, бачить однакові 12.
04. [Коли групи не однакові](./04-practice.md) — Учень знаходить модель рівних груп і пояснювальну картку «порівну».
05. [Склади свої групи](./05-transfer.md) — Учень розкладає по два, складає 2+2+2+2=8 та 4×2=8.

## Режисерські принципи

Математичний сенс кожної дії має бути видимим: **кількість груп × кількість у групі** або два різні види ділення (розподіл порівну / утворення груп заданого розміру). Не ототожнювати групи з окремими предметами. Ділення на нуль не дозволене, нульове ділене можливе при ненульовому дільнику. Усе є сценарним draft; медіа та реалізації немає.

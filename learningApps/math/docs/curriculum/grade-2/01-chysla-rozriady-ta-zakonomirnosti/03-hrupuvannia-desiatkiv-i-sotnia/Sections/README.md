# Сценарій: Групування десятків і сотня

> Educational Screenwriter · draft. Навчальна мета й точні статичні Skill ID залишаються в [методичній картці](../README.md). Повний Learning Brief потребує окремого проходу.

## Послідовність секцій

01. [Великі групи рахувати простіше](./01-concept.md) — Учень натискає пучки: 10,20,.
02. [Збираємо десять десятків](./02-example.md) — Учень послідовно додає десятий пучок до дев’яти, бачить число 100 та модель сотенної плитки.
03. [Обмін без зміни кількості](./03-model.md) — Учень обирає «Згрупувати» і «Розгрупувати» та перевіряє обидві моделі.
04. [99 і ще один](./04-practice.md) — Учень утворює десятий пучок із десяти одиниць, потім сотню, зберігаючи всі предмети.
05. [Рахуємо великі набори](./05-transfer.md) — Учень називає 86 і 94, перевіряє через відкриття груп і порівняння десятків.
06. [Підсумок: десять десятків](./06-summary.md) — Учень відновлює ланцюжок обміну та прослуховує підсумок.

## Межі та постановка

Не перетворювати Grade 2 на навчання довільних тризначних чисел: сотня — модель групування, лічба сотнями — коротке ознайомлення. Приклади мають бути арифметично узгоджені, а розряди — явно підписані. Зображення, голос і UI описані як майбутні потреби; немає коду, готових ресурсів чи тесту mastery.

## Режисерські принципи

Математичний зміст усіх даних зберігається при переході між моделями. Часові шкали та стрілки годинника мають коректні положення, категорії в таблицях і діаграмах мають спільну шкалу, імовірність формулюється без удаваної гарантії. Гроші показано через **умовну валюту «од.»** — не чинні номінали жодної країни. Це сценарії для редакційного рев’ю, без готових компонентів, медіа чи тестів.

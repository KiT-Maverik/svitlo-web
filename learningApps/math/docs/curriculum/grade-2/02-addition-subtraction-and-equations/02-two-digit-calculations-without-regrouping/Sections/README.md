# Сценарій уроку «Двоцифрові числа без обміну»

> Educational Screenwriter · draft. [Коротка методична картка](../README.md) є джерелом навчальних цілей та Skill ID. Повний Learning Brief ще не написано.

## Послідовність

01. [Порівну десятків і одиниць](./01-concept.md) — Учень окремо об’єднує пучки й палички, бачить 3 десятки/7 одиниць.
02. [Віднімаємо без розміну](./02-example.md) — Учень вилучає 2 пучки й 5 одиниць, добирає 43.
03. [Спочатку одиниці чи десятки?](./03-model.md) — Учень виконує розрядні частини у довільному порядку, отримує 78.
04. [Перевір подумки](./04-practice.md) — Учень обирає 46 та 61, за потреби розкриває пучки.
05. [Чому тут не потрібен обмін?](./05-transfer.md) — Учень визначає, де можна діяти без обміну, не зобов’язаний поки обчислити другий приклад.
06. [Підсумок розрядного способу](./06-summary.md) — Учень зіставляє моделі і результати, може виправити одну помилку за підказкою.

## Педагогічні межі

Обміни десяток ↔ десять одиниць повинні зберігати кількість. Перенос і розгрупування показуються предметно перед символічними кроками. Приклади арифметично перевірені авторським сценарієм, але перед публікацією потрібне методичне рев’ю. Інтерактиви — практика, а не оцінювання. Ресурси лише заплановані.

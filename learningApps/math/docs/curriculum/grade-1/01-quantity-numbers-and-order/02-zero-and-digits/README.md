# Zero and Digits

> **Curriculum: Mathematics — Grade 1 · Quantity, Numbers, and Order · Lesson 02**
> **Status:** Methodological Learning Brief awaiting editorial review; not an implemented lesson, screenplay, or Assessment Specification.

**Learning objective:** Recognize zero and connect digits 0–9 with quantities.

**Target audience:** Beginning mathematics learners, approximately ages 6–7. This age estimate is not an access restriction.

## Target Skills

- [Zero](../../../../../src/data/skillsTaxonomy/counting/cardinality/skills/zero.data.ts)
- [Digits 09](../../../../../src/data/skillsTaxonomy/numeration/notation/skills/digits09.data.ts)

## Prerequisites

Experience counting small groups and understanding that the final counting word describes their size.

## Expected learning outcomes

After learning the material, the learner:

- Recognize an empty group as containing zero elements.
- Match the symbol 0 to the absence of elements in a specified group.
- Recognize and write the ten digits from 0 to 9.
- Distinguish a digit as a symbol from a number as a quantity or value.

## Mathematical content

- Zero is a number expressing the cardinality of an empty set.
- Digits 0–9 are the basic symbols used to write numbers; a numeral may contain multiple digits.
- Zero items in a particular group does not mean that no object or container exists.

## Scope and boundaries

Introduce digits 0–9 without a formal account of the positional numeral system. Recognizing all ten digits is not equivalent to reading every number through twenty.

## Typical misconceptions and risks

- Treating zero as a missing response rather than a number.
- Confusing a digit's name with a multi-digit numeral.
- Assuming the number ten is itself an additional digit.

## Indicators of learning objective attainment

These are **pedagogical guidelines for future assessment design**, not finalized questions, scoring thresholds, or mastery judgments.

- Identifies an empty set as having cardinality zero.
- Matches familiar one-digit quantities with their numerals.
- Explains how a number can contain more than one digit.

## Connection to learning sequence

Extend the number-word sequence through twenty; place-value concepts are introduced separately.

# Quantity, Numbers, and Order

> **Curriculum: Grade 1 · модуль 01**  
> **Статус:** 11 методичних Learning Briefs та 69 сценарних секцій у статусі draft; потрібен редакційний перегляд.

**Джерело порядку та Skill ID:** [Curriculum Grade 1](../grade-1.curriculum.md). Це навчальний модуль, а не SkillGroup з таксономії.

## Мета модуля

Закласти розуміння кількості, лічби 0–20, запису й порядку чисел, порівняння, числової прямої та групування. Учень переходить від конкретних предметів до числових позначень і пов'язує різні представлення одного числа.

**Передумови:** спеціальні математичні навички не обов’язкові; підтримується учень, який тільки опановує читання.

**Методичний принцип:** спочатку значення та спостережувані дії, потім символи й узагальнення. Не змішувати в один доказ опанування різні Skill без достатніх підстав. Модуль не містить сценаріїв, вправ або конкретних UI-рішень.

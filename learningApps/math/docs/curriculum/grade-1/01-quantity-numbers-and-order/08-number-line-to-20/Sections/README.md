# Сценарій: Числова пряма до 20

> Чернетка Educational Screenwriter. [Методичний Learning Brief](../README.md) є основою; тут тільки сценарій взаємодії.

## Секції

01. [Від доріжки до прямої](./01-vid-dorizhky-do-priamoi.md) — Пояснити числову пряму як просторову модель впорядкованих чисел із рівними кроками.
02. [Нуль — теж позначка](./02-nul-tezh-poznachka.md) — Розмістити нуль на прямій і показати послідовність від 0, не представляючи його кінцем усіх можливих чисел.
03. [Знайди місце числа](./03-znaidy-mistse-chysla.md) — Побудувати відображення число → точка для цілого діапазону 0–20.
04. [Яке число на цій рисці?](./04-iake-chyslo-na-tsii-rystsi.md) — Перевірити обернене відображення точка → число.
05. [Лівіше чи правіше?](./05-livishe-chy-pravishe.md) — Пов’язати порядок чисел із просторовим розміщенням на орієнтованій прямій.
06. [Віднови пропущені риски](./06-vidnovy-propushcheni-rysky.md) — Узагальнити рівномірний масштаб і читання частково розміченої прямої.

## Режисерські принципи

Всі кроки на прямій — однакові за довжиною; тільки цілі 0–20 та стандартна орієнтація зростання праворуч. Важливі дії керовані учнем. Аудіо, векторні елементи та картки описані як ресурси для майбутнього виготовлення; відео не потрібно. Це тренувальна практика, а не формальне оцінювання.

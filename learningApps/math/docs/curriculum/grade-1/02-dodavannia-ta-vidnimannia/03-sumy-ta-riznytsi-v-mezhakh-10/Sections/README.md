## Педагогічне питання на рев’ю

Цей урок стоїть **перед** уроком 08 «Що означає відняти», хоча Skill `math.addsub.facts-within-10` охоплює і віднімання. Сценарій тому вводить різницю лише предметною дією «забрали / залишилось», без вимоги знати формальний запис віднімання. **Методист має перевірити порядок уроків** перед публікацією; це не доказ опанування формальних subtraction facts.

Візуальні та звукові ресурси поки лише запропоновані; відео не потрібне. Без оцінок, таймерів, обов’язкового письма й неозвучених складних умов.

# How Many More or Fewer

> **Curriculum: Mathematics — Grade 1 · Mathematical Language, Equalities, and Word Problems · Lesson 06**

## Learning objective

Compare quantities and describe increases or decreases.

Distinguish 'how many more' comparisons from changes in a single quantity.

## Сценарії взаємодії (Educational Screenwriter · draft)

У всіх 8 уроках зібрано по 6 сценарних Markdown-секцій (**48 секцій**). Кожна описує сцену, репліки, керовані учнем інтерактиви, педагогічні підказки, майбутні ресурси та доступність. Це не медіафайли, код або формальне оцінювання.

**Методична примітка:** повні Learning Briefs для цього модуля ще відсутні. Перед затвердженням потрібен перегляд сценаріїв методистом. Особливо важливо не плутати фізичні сантиметри з пікселями не відкаліброваного екрана; також розмежовувати порівняння маси та місткості.

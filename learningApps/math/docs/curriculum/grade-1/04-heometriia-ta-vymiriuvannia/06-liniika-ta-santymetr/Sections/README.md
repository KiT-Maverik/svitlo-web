## Режисерські зауваги

На віртуальній лінійці сантиметри є внутрішніми одиницями сцени: **не стверджувати**, що виведений на будь-який екран відрізок має задану фізичну довжину без калібрування. Відлік починається з риски 0, рахуються інтервали.

Візуалізації, аудіо та плашки — лише вимоги до створення ресурсів; відео не потрібне. Практика з підказками не замінює незалежного оцінювання. Написи й пояснення локалізуються.

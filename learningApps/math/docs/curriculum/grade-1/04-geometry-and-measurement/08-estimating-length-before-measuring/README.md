# Estimating Length Before Measuring

> **Curriculum: Mathematics — Grade 1 · Geometry and Measurement · Lesson 08**
> **Status:** Draft lesson card; a complete methodological Learning Brief has not yet been written.

## Learning objective

Estimate length, then test the estimate by measuring.

Use a reference length, compare estimated and measured results, and learn from the difference.

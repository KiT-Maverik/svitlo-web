# Rulers and Centimeters

> **Curriculum: Mathematics — Grade 1 · Geometry and Measurement · Lesson 06**
> **Status:** Draft lesson card; a complete methodological Learning Brief has not yet been written.

## Learning objective

Measure from a ruler's zero mark and draw a given length.

Count centimeter intervals rather than tick marks; use a consistent virtual scale.

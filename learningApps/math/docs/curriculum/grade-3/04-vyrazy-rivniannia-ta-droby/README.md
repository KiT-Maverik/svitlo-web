# Вирази, рівняння та дроби

> **Curriculum: Grade 3 · модуль 04**  
> **Статус:** уроки заплановані; повні методичні специфікації ще не створені.

**Джерело порядку та Skill ID:** [Curriculum Grade 3](../../grade-3.md). Це навчальний модуль, а не SkillGroup з таксономії.

## Уроки

- 01. [Порядок арифметичних дій](./01-poriadok-aryfmetychnykh-dii/README.md) — Виконує багатодійні вирази та знаходить порушення правил.
- 02. [Буквений вираз](./02-bukvenyi-vyraz/README.md) — Підставляє значення змінної у простий вираз.
- 03. [Невідомі ділене й дільник](./03-nevidomi-dilene-i-dilnyk/README.md) — Знаходить невідомий компонент ділення.
- 04. [Ціле та рівні частини](./04-tsile-ta-rivni-chastyny/README.md) — Розрізняє правильне поділення цілого на рівні частини.
- 05. [Одиничний дріб](./05-odynychnyi-drib/README.md) — Будує, називає та пояснює одиничні дроби.
- 06. [Порівняння одиничних дробів](./06-porivniannia-odynychnykh-drobiv/README.md) — Порівнює рівні частини одного цілого.
- 07. [Частина числа й ціле за частиною](./07-chastyna-chysla-i-tsile-za-chastynoiu/README.md) — Знаходить одиничну частину величини й відновлює ціле.
- 08. [Додавання й віднімання однойменних дробів](./08-dodavannia-i-vidnimannia-odnoimennykh-drobiv/README.md) — Моделює прості дії з дробами в межах цілого.
- 09. [Десяті та дроби більші за одиницю](./09-desiati-ta-droby-bilshi-za-odynytsiu/README.md) — Пояснює зв’язок десятих із діленням та моделює дроби понад один.

- 03. [Сполучний і розподільний закони множення](./03-associative-and-distributive-properties/README.md) — Перегруповує множники та розкладає множник на частини.

- 11. [Ділення двоцифрового числа на одноцифрове](./11-dividing-a-two-digit-number-by-one-digit/README.md) — Виконує позатабличне ділення.
- 12. [Ділення з остачею](./12-division-with-a-remainder/README.md) — Знаходить остачу, перевіряє її межі й правильність.
- 13. [Знаходимо помилку в діленні](./13-finding-errors-in-division/README.md) — Викриває некоректну частку або остачу.

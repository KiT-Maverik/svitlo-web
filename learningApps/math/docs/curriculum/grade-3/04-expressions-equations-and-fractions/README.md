# Вирази, рівняння та дроби

> **Curriculum: Grade 3 · модуль 04**  
> **Статус:** уроки заплановані; повні методичні специфікації ще не створені.

**Джерело порядку та Skill ID:** [Curriculum Grade 3](../grade-3.curriculum.md). Це навчальний модуль, а не SkillGroup з таксономії.

## Уроки

- 01. [Порядок арифметичних дій](./01-order-of-operations/README.md) — Виконує багатодійні вирази та знаходить порушення правил.
- 02. [Буквений вираз](./02-expressions-with-variables/README.md) — Підставляє значення змінної у простий вираз.
- 03. [Невідомі ділене й дільник](./03-unknown-dividend-and-divisor/README.md) — Знаходить невідомий компонент ділення.
- 04. [Ціле та рівні частини](./04-whole-and-equal-parts/README.md) — Розрізняє правильне поділення цілого на рівні частини.
- 05. [Одиничний дріб](./05-unit-fractions/README.md) — Будує, називає та пояснює одиничні дроби.
- 06. [Порівняння одиничних дробів](./06-comparing-unit-fractions/README.md) — Порівнює рівні частини одного цілого.
- 07. [Частина числа й ціле за частиною](./07-finding-a-fraction-of-a-number-and-the-whole/README.md) — Знаходить одиничну частину величини й відновлює ціле.
- 08. [Додавання й віднімання однойменних дробів](./08-adding-and-subtracting-like-fractions/README.md) — Моделює прості дії з дробами в межах цілого.
- 09. [Десяті та дроби більші за одиницю](./09-tenths-and-fractions-greater-than-one/README.md) — Пояснює зв’язок десятих із діленням та моделює дроби понад один.

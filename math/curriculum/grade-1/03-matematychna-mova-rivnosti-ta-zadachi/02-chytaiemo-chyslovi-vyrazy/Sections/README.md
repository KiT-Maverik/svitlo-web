# Сценарій: Читаємо числові вирази

> **Educational Screenwriter · storyboard draft.** [Методична картка](../README.md) містить мету та існуючі Skill ID; повного методичного Learning Brief для цього уроку ще немає.

## Послідовність секцій

01. [Число, знак, число](./01-chyslo-znak-chyslo.md) — На екрані «4 + 2» великими символами, під кожною частиною відповідно чотири і два яблука. Плашка «Числовий вираз»..
02. [Плюс говорить про об'єднання](./02-plius-hovoryt-pro-obiednannia.md) — Запис «3 + 5» і дві групи різнокольорових фішок у прозорих рамках. Нижче кнопка «Покажи дію»..
03. [Мінус означає взяти частину](./03-minus-oznachaie-vziaty-chastynu.md) — Великий запис «9 − 4» і дев’ять кружечків; чотири позначені як ті, що забираємо. Плашка «Прочитай дію»..
04. [Вираз і рівність — це не те саме](./04-vyraz-i-rivnist-tse-ne-te-same.md) — Зліва велика картка «6 + 2», праворуч «6 + 2 = 8». Плашка «Спочатку дія; далі твердження про результат»..
05. [Послухай і знайди вираз](./05-poslukhai-i-znaidy-vyraz.md) — На дошці три записи: «5 + 1», «5 − 1», «1 + 5». Голос просить «п’ять мінус один», згодом «один плюс п’ять»..
06. [Поясни вираз предметами](./06-poiasny-vyraz-predmetamy.md) — Дві короткі задачі без сюжету: «7 − 2» і «4 + 3». Поруч доступні жетони в окремих групах. Плашка «Обери, що робити з предметами»..

## Режисерські принципи

Вираз на кшталт `3 + 5` не тотожний твердженню `3 + 5 = 8`; порядок чисел та знаків під час читання є частиною завдання.

Усі плашки, предметні моделі, озвучені репліки та керовані анімації є **сценарними вимогами**, а не готовими медіафайлами або компонентами. Відео не потрібне. Учень може повторювати, помилятися та користуватися змістовними підказками; формальне оцінювання й діагностика — окрема роль. Текст, аудіо й описи повинні локалізуватися.

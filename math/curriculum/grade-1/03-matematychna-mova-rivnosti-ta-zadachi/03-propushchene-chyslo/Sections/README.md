# Сценарій: Пропущене число

> **Educational Screenwriter · storyboard draft.** [Методична картка](../README.md) містить мету та існуючі Skill ID; повного методичного Learning Brief для цього уроку ще немає.

## Послідовність секцій

01. [Порожнє місце в рівності](./01-porozhnie-mistse-v-rivnosti.md) — Велика картка «3 + □ = 5». Під нею три зелені фішки у рамці для п’яти, ще два вільні місця. Плашка «Знайди, чого бракує»..
02. [Невідомий доданок — у першому місці](./02-nevidomyi-dodanok-u-pershomu-mistsi.md) — Запис «□ + 4 = 7», предметна модель семи фішок, чотири з яких виділені як відома частина. Плашка «Частина може стояти зліва»..
03. [Невідоме може стояти праворуч](./03-nevidome-mozhe-stoiaty-pravoruch.md) — Запис «6 + 2 = □», велика рамка із шістьма та двома предметами. Є підпис «Чи залишилися рівними дві сторони?»..
04. [Дві сторони з діями](./04-dvi-storony-z-diiamy.md) — Запис «2 + □ = 3 + 4», під ним дві незалежні предметні моделі. Плашка «Перевір обидва боки»..
05. [Вибери число, а не вгадуй](./05-vybery-chyslo-a-ne-vhadui.md) — Три короткі рівності «5 + □ = 8», «□ + 1 = 6», «4 + □ = 4». Картки 0–8 та кнопка «Покажи модель»..
06. [Підсумок: перевіряй підстановкою](./06-pidsumok-pereviriai-pidstanovkoiu.md) — Два стани одного запису: «2 + □ = 6» і «2 + 4 = 6». Біля них модель із двох та чотирьох фішок..

## Режисерські принципи

Невідомий доданок може стояти **до**, **після** знака плюс, а також результат може стояти після =. Учень перевіряє підстановкою.

Усі плашки, предметні моделі, озвучені репліки та керовані анімації є **сценарними вимогами**, а не готовими медіафайлами або компонентами. Відео не потрібне. Учень може повторювати, помилятися та користуватися змістовними підказками; формальне оцінювання й діагностика — окрема роль. Текст, аудіо й описи повинні локалізуватися.

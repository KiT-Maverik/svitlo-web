06. [Фінальна історія: обери, покажи, поясни](./06-finalna-istoriia-obery-pokazhy-poiasny.md) — Інтегрувати ситуацію, математичну модель і аргумент без формального іспиту.

## Режисерські зауваги

Останній урок підсумовує зв’язок **історія → модель → вираз → аргумент**. Пояснення можна добирати текстовими картками, не вимагаючи мікрофона або тривалого письма; це не підсумковий іспит.

Відео не потрібне: сцени пропонують дослідницькі взаємодії. Ілюстрації й аудіо — лише вимоги до ресурсів; формальна перевірка Skill потребує окремої специфікації. Усі тексти й альтернативні описи локалізуються.

# Сценарій: Грошові номінали та суми

> **Educational Screenwriter — чернетка.** [Методична картка](../README.md) — джерело Skill ID; повний Learning Brief ще не написано.

## Послідовність

01. [Яка це грошова одиниця?](./01-iaka-tse-hroshova-odynytsia-.md) — Вводити ідею номіналу через конфігурацію валюти, не припускаючи універсальних монет.
02. [Декілька однакових номіналів](./02-dekilka-odnakovykh-nominaliv.md) — Показати складання суми з кількох грошових одиниць одного номіналу.
03. [Різні номінали — одна сума](./03-rizni-nominaly-odna-suma.md) — Знайти кілька способів зібрати однакову суму.
04. [Порівняй дві суми](./04-porivniai-dvi-sumy.md) — Відділити загальну вартість від кількості грошових карток.
05. [Збери точну суму для покупки](./05-zbery-tochnu-sumu-dlia-pokupky.md) — Побудувати просту ситуацію вибору вартості без вимоги решти, податків чи курсів.
06. [Підсумок і перенесення на реальні валюти](./06-pidsumok-i-perenesennia-na-realni-valiuty.md) — Підсумувати номінал, суму та порівняння, залишаючи валюту параметром програми.

## Режисерські межі

Сценарій користується **умовною валютою «од.»** із навчальними номіналами 1,2,5. Це НЕ твердження про дійсні номінали будь-якої валюти. Реальна валюта вимагає окремо перевіреного набору номіналів/зображень і локалізованих назв.

Аудіо й векторні сцени лише заплановані; відео не потрібне. Не зберігати персональні дати чи фінансові дані. Дитина керує темпом, повторює навчальні спроби, а Assessment Architect проєктуватиме оцінювання окремо.

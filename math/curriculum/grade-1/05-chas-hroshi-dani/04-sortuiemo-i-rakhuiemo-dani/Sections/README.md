# Сценарій: Сортуємо й рахуємо дані

> Educational Screenwriter · draft. [Коротка методична картка](../README.md) визначає навчальну мету та Target Skills; повного Learning Brief ще немає.

## Послідовність

01. [Чим відрізняються предмети?](./01-chym-vidrizniaiutsia-predmety-.md) — Виявити одну ознаку для класифікації замість випадкового групування.
02. [Форма — інша ознака](./02-forma-insha-oznaka.md) — Відрізняти класифікацію за формою від попередньої класифікації за кольором.
03. [Порахуємо кожну групу](./03-porakhuiemo-kozhnu-hrupu.md) — Перейти від сортування до таблиці частот, не змішуючи кількість груп із кількістю елементів.
04. [Перевір, чи ніхто не загубився](./04-perevir-chy-nikhto-ne-zahubyvsia.md) — Застосувати контроль загальної кількості під час збору частот.
05. [Зробімо власне опитування предметів](./05-zrobimo-vlasne-opytuvannia-predmetiv.md) — Побудувати частоти для нового набору за єдиною заданою ознакою.
06. [Підсумок: ознака, група, кількість](./06-pidsumok-oznaka-hrupa-kilkist.md) — Три підсумкові картки «Обери ознаку», «Розклади», «Порахуй». Поруч набір 6 фігур — по 2 червоні, сині, жовті.

## Режисерські зауваги

Класифікація: в межах одного раунду **єдина визначена ознака**, кожен предмет належить рівно одній групі. Після сортування перевірити частоти та загальну кількість предметів.

Відео не потрібне: сцени пропонують дослідницькі взаємодії. Ілюстрації й аудіо — лише вимоги до ресурсів; формальна перевірка Skill потребує окремої специфікації. Усі тексти й альтернативні описи локалізуються.

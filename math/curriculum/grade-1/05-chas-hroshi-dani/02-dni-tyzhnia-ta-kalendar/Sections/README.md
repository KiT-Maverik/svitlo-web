# Сценарій: Дні тижня та календар

> **Educational Screenwriter — чернетка.** [Методична картка](../README.md) — джерело Skill ID; повний Learning Brief ще не написано.

## Послідовність

01. [Сім днів — один тиждень](./01-sim-dniv-odyn-tyzhden.md) — Назвати сім днів тижня та послідовність без припущень про перший день локального календарного рядка.
02. [Учора, сьогодні, завтра](./02-uchora-sohodni-zavtra.md) — Визначати попередній і наступний день у межах тижня.
03. [Календар — рядки та клітинки](./03-kalendar-riadky-ta-klitynky.md) — Зрозуміти календарний місяць як упорядковані дати, а не просто набір чисел.
04. [Місяці року по порядку](./04-misiatsi-roku-po-poriadku.md) — Назвати 12 місяців року в послідовності цивільного григоріанського календаря.
05. [Постав подію в календар](./05-postav-podiiu-v-kalendar.md) — Перенести дні та дати на просте планування без реальної персональної інформації.
06. [Підсумок: день, тиждень, місяць](./06-pidsumok-den-tyzhden-misiats.md) — Узагальнити співвідношення днів, тижнів, місяців та навчального року без твердження «місяць — рівно чотири тижні».

## Режисерські межі

Універсальна програма використовує назви днів і місяців локалізовано. Перший стовпець тижня — налаштування локалі; **не стверджувати, що в кожному місяці рівно чотири тижні**. Відмічати, коли календар умовний.

Аудіо й векторні сцени лише заплановані; відео не потрібне. Не зберігати персональні дати чи фінансові дані. Дитина керує темпом, повторює навчальні спроби, а Assessment Architect проєктуватиме оцінювання окремо.

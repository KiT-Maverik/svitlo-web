## Загальна режисура

Навчаємо через предметні кількості та поділ на групи, без формальних арифметичних алгоритмів. Аудіо та графіка описані лише як майбутні ресурси. Учень має право повтору й підказки без штрафів. Відео не потрібне, дії доступні без перетягування. Формальна перевірка Skills — окремий етап.

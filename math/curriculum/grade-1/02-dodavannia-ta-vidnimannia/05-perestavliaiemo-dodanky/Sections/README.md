# Сценарій: Переставляємо доданки

> Draft Educational Screenwriter; [методична картка](../README.md) визначає Skill і навчальну мету.

## Секції
01. [Дві групи, один результат](./01-dvi-hrupy-odyn-rezultat.md) — Показати переставність двох груп.
02. [Чи змінилася кількість?](./02-chy-zminylasia-kilkist.md) — Зберегти сенс кількості за зміни порядку.
03. [Картки рівнозначних прикладів](./03-kartky-rivnoznachnykh-prykladiv.md) — Зіставити рівні суми в записах.
04. [Однакові чи різні доданки?](./04-odnakovi-chy-rizni-dodanky.md) — Розглянути випадок однакових доданків.
05. [Додамо нуль з іншого боку](./05-dodamo-nul-z-inshoho-boku.md) — Перевірити правило для нуля.
06. [Підсумок: порядок не змінює суму](./06-pidsumok-poriadok-ne-zminiuie-sumu.md) — Сформулювати правило власними словами.

Правило виводимо з незмінності *тих самих предметів*, а не з магічного переставляння цифр. Тільки додавання, не приписувати переставність відніманню. Відео не потрібне; аудіо і графіка плануються. Секції містять навчальну практику, а не формальну перевірку mastery.

# Сценарій: Додавання з переходом через десяток

> Educational Screenwriter draft; [методична картка](../README.md) — ціль і Target Skill.

## Послідовність
01. [Де закінчується перший десяток](./01-de-zakinchuietsia-pershyi-desiatok.md) — Пов’язати перехід із досягненням десятки.
02. [Розділи шість на дві частини](./02-rozdily-shist-na-dvi-chastyny.md) — Розбити другий доданок для доповнення першого.
03. [Результат чотирнадцять](./03-rezultat-chotyrnadtsiat.md) — Знайти суму з повного десятка і залишку.
04. [Інший приклад: дев’ять плюс сім](./04-deviat-plius-sim.md) — Відпрацювати перехід з 9.
05. [Твоя черга: сім плюс п’ять](./05-sim-plius-piat.md) — Самостійно повторити алгоритм з 7.
06. [Підсумок переходу через 10](./06-pidsumok-perekhodu.md) — Узагальнити послідовність обчислення.

Математична логіка: **8+6 = 8+(2+4) = 10+4 = 14**; зберігаємо загальну кількість. Ця декомпозиція пояснюється фішками, а не вимагає формального алгебраїчного запису від учня. Відео не потрібне, краще працює керована симуляція. Ресурси не створювали; формальний assessment — окремий етап.

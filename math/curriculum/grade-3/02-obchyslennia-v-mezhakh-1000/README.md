# Обчислення в межах 1000

> **Curriculum: Grade 3 · модуль 02**  
> **Статус:** уроки заплановані; повні методичні специфікації ще не створені.

**Джерело порядку та Skill ID:** [Curriculum Grade 3](../../grade-3.md). Це навчальний модуль, а не SkillGroup з таксономії.

## Уроки

- 01. [Сотні та десятки в обчисленнях](./01-sotni-ta-desiatky-v-obchyslenniakh/README.md) — Виконує дії з круглими сотнями та десятками.
- 02. [Трицифрові числа без перегрупування](./02-trytsyfrovi-chysla-bez-perehrupuvannia/README.md) — Додає й віднімає без розрядного обміну.
- 03. [Додавання трицифрових із переносом](./03-dodavannia-trytsyfrovykh-iz-perenosom/README.md) — Коректно обмінює розряди в письмових обчисленнях.
- 04. [Віднімання трицифрових із позичанням](./04-vidnimannia-trytsyfrovykh-iz-pozychanniam/README.md) — Розгруповує сотні/десятки у письмовому відніманні.
- 05. [Як перевірити складне обчислення](./05-iak-pereviryty-skladne-obchyslennia/README.md) — Оцінює результат, перевіряє оберненою дією та виправляє помилки.
- 06. [Зручне групування доданків](./06-zruchne-hrupuvannia-dodankiv/README.md) — Перегруповує доданки без зміни суми.

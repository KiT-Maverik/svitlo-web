# Grade 4 · Module 1: Числа та обчислення

> **Статус:** поки лише перелік запланованих уроків; детальні методичні описи не створені.

**Джерело порядку та Skill ID:** [Grade 4 Curriculum](../../grade-4.md). Модуль — навчальна одиниця, а не SkillGroup з таксономії.

## Уроки

- 1. Округлення до сотень — Пояснює результат округлення й приблизну похибку.
- 2. Множення трицифрового числа на одноцифрове — Розкладає множене на розрядні складові; результат залишається в межах 1000.
- 3. Ділення трицифрового числа на одноцифрове — Обчислює доступні випадки через розрядний розклад.
- 4. Складні вирази та перевірка результату — Застосовує порядок дій, оцінювання та альтернативні способи.
- 5. Задачі на три дії — Планує й пояснює нескладні трьохкрокові розв’язання.

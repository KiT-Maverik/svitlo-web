# Сценарій уроку «Відомостей забагато чи бракує»

> Educational Screenwriter · draft. Навчальні цілі й Skill ID зберігаються в [методичній картці](../README.md); повний Learning Brief ще не написано.

## Послідовність

01. [Знайди лише потрібні дані](./01-concept.md) — Учень обирає числові дані й відмічає декоративний опис.
02. [Коли інформації не вистачає](./02-example.md) — Учень обирає «бракує кількості забраних», не вгадує результат.
03. [Зайве число в історії](./03-model.md) — Учень знаходить 12+8=20, відкидає 3.
04. [Додаємо потрібну умову](./04-practice.md) — Учень знаходить □=12 через 30−18, отримує повну задачу.
05. [Дані суперечать одне одному](./05-transfer.md) — Учень знаходить суперечність і обирає пояснення, а не намагається обчислити.
06. [Підсумок перевірки умови](./06-summary.md) — Учень класифікує кожну умову, потім вирішує лише повну.

## Режисерські принципи

Математичний зміст усіх даних зберігається при переході між моделями. Часові шкали та стрілки годинника мають коректні положення, категорії в таблицях і діаграмах мають спільну шкалу, імовірність формулюється без удаваної гарантії. Гроші показано через **умовну валюту «од.»** — не чинні номінали жодної країни. Це сценарії для редакційного рев’ю, без готових компонентів, медіа чи тестів.

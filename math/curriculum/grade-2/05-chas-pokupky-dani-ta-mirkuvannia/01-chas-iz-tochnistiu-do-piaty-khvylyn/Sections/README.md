# Сценарій уроку «Час із точністю до п’яти хвилин»

> Educational Screenwriter · draft. Навчальні цілі й Skill ID зберігаються в [методичній картці](../README.md); повний Learning Brief ще не написано.

## Послідовність

01. [Половина години](./01-concept.md) — Учень обирає цифровий запис 3:30 і показує хвилинну стрілку на шести.
02. [Чверть години](./02-example.md) — Учень співвідносить 4:15 і 4:45 з відповідними стрілками.
03. [Кожна цифра — п’ять хвилин](./03-model.md) — Учень крокує хвилинною стрілкою 0→5→10→15, бачить 2:15.
04. [Читаємо 7:25](./04-practice.md) — Учень читає 7:25 і звіряє з цифровим записом.
05. [Проста тривалість](./05-transfer.md) — Учень робить чотири п’ятихвилинні кроки та рахує 20.
06. [Перехід через повну годину](./06-summary.md) — Учень проходить два кроки, обирає 20 хвилин.

## Режисерські принципи

Математичний зміст усіх даних зберігається при переході між моделями. Часові шкали та стрілки годинника мають коректні положення, категорії в таблицях і діаграмах мають спільну шкалу, імовірність формулюється без удаваної гарантії. Гроші показано через **умовну валюту «од.»** — не чинні номінали жодної країни. Це сценарії для редакційного рев’ю, без готових компонентів, медіа чи тестів.

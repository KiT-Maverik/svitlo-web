# Сценарій уроку «Периметр як довжина межі»

## Секції

01. [Обійдемо контур](./01-concept.md) — Учень активує сторони по черзі, повертається у стартову вершину.
02. [Довжини сторін](./02-example.md) — Учень читає чотири числа і складає 5+3+5+3=16 см.
03. [Квадрат має рівні сторони](./03-model.md) — Учень додає 4+4+4+4=16 см, порівнює з 4×4.
04. [Периметр іншої фігури](./04-practice.md) — Учень додає всі три довжини та називає одиницю.
05. [Однаковий периметр — різна форма](./05-transfer.md) — Учень обчислює 2+6+2+6 та 3+5+3+5, порівнює 16 і 16.
06. [Підсумок межі](./06-summary.md) — Учень заповнює відсутнє число та відновлює повний обхід.

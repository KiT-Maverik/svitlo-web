# Сценарій: Лічба десятками й сотнями

> Educational Screenwriter · draft. Навчальна мета й точні статичні Skill ID залишаються в [методичній картці](../README.md). Повний Learning Brief потребує окремого проходу.

## Послідовність секцій

01. [Сходинки по десять](./01-concept.md) — Учень натискає «+10» від 0 до 100, чує назву результату.
02. [Почни з 30](./02-example.md) — Учень заповнює 40,50,60; повторює від 50.
03. [Не нульові одиниці](./03-model.md) — Учень заповнює 44 та 64 на наступному кроці.
04. [Назад десятками](./04-practice.md) — Учень добирає 60 і проходить зворотну доріжку.
05. [Сто і ще сто: лише як погляд уперед](./05-transfer.md) — Учень натискає другу плитку, бачить 200 як дві сотні, не проходить вправи на розряди тисяч.
06. [Підсумок різних кроків](./06-summary.md) — Учень обирає правило для двох рядів і завершує.

## Межі та постановка

Не перетворювати Grade 2 на навчання довільних тризначних чисел: сотня — модель групування, лічба сотнями — коротке ознайомлення. Приклади мають бути арифметично узгоджені, а розряди — явно підписані. Зображення, голос і UI описані як майбутні потреби; немає коду, готових ресурсів чи тесту mastery.

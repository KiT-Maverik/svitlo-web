# Review Recommendations from Error History

**Status:** Proposed — not implemented by this document.
**Area:** learning

## Goal

Recommend useful next practice based on actual evidence rather than arbitrary engagement.

## Intended scope

- Analyze error frequency, recency, repetitions, question difficulty and coverage per Skill.
- Propose practice or revisiting Lessons without claiming medical/scientific certainty.
- Respect incomplete evidence, under-covered skills, last-success vs last-error and learner workload.
- Explain recommendations in understandable learner language.

## Open decisions and constraints

Define and validate evidence/ranking algorithm; avoid stigmatizing low performance.

**Implementation note:** Backlog only, not an approved new runtime contract or claim of functionality.

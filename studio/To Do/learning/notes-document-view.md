# Unlocked Notes: Document / Outline Viewer

**Status:** Proposed — not implemented by this document.
**Area:** learning

## Goal

Present the learner's unlocked atomic Notes as an ordered lesson-structured revision document.

## Intended scope

- Group notes by Program/module/Lesson/Section and respect stable authored IDs and unlock order.
- Allow partial disclosure: show unopened-note indicators without leaking locked educational content.
- Support offline reading, RTL/LTR, search, print/export as optional future enhancements.
- Never substitute a full Lesson recap for concise recall cues.

## Open decisions and constraints

Define note lifecycle, unlock consistency, hiding/showing locked items and privacy.

**Implementation note:** Backlog only, not an approved new runtime contract or claim of functionality.

# Flashcard Cram / Free Review Mode

**Status:** Proposed — not implemented by this document.
**Area:** learning

## Goal

Provide optional unscheduled practice with available flashcards.

## Intended scope

- Allow selecting all available/unlocked cards or a chosen deck and repeating freely.
- Keep cram mode separate from adaptive scheduled review progression so it cannot game evidence.
- Provide shuffling, feedback, localization and accessibility.

## Open decisions and constraints

Decide whether free repetition influences future scheduling and skill estimates.

**Implementation note:** Backlog only, not an approved new runtime contract or claim of functionality.

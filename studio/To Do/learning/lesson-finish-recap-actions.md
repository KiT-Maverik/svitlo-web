# Lesson Completion: Unlocks, Next Steps & Quiz Options

**Status:** Proposed — not implemented by this document.
**Area:** learning

## Goal

Turn completion into useful feedback and voluntary next action.

## Intended scope

- Show newly available Notes, Flashcards and verified learning Skills/evidence; don't claim mastery from simply viewing a Lesson.
- Offer next practice, additional generated questions or optional Quiz.
- Allow the Quiz immediately in the current flow or save it for later.
- Support accessible/RTL text and independent Program success-screen extension without changing learning facts.

## Open decisions and constraints

Define result vs content completion and which unlocks are actually available.

**Implementation note:** Backlog only, not an approved new runtime contract or claim of functionality.

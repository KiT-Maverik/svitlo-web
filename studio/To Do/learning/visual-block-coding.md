# Visual Block Coding Playground for Children

**Status:** Proposed — not implemented by this document.
**Area:** learning

## Goal

Offer an introductory programming environment based on connected blocks.

## Intended scope

- Provide drag/keyboard-accessible blocks that assemble algorithms; show program state and outcome.
- Explore existing block-language frameworks and licensing (e.g. Blockly as candidate), not assume one chosen.
- Support translation, RTL, assistive access and a meaningful transition to textual coding.
- Allow classroom and offline package scenarios.

## Open decisions and constraints

Choose Blockly/framework, block semantics, persistence/export and integration with Coding Workspace.

**Implementation note:** Backlog only, not an approved new runtime contract or claim of functionality.

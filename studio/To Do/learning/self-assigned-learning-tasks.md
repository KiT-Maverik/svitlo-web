# Personal Learning Tasks

**Status:** Proposed — not implemented by this document.
**Area:** learning

## Goal

Let a learner create assignments for themselves.

## Intended scope

- Allow scheduling a Lesson, Quiz, flashcard set, or personal practice task for later.
- Define due dates, priority and completion separately from teacher assignments.
- Support local/offline task list with optional reminder/notification opt-in.
- Show overdue work without guilt or unhealthy engagement pressure.

## Open decisions and constraints

Decide reminders, frequency, privacy and integration with review scheduling.

**Implementation note:** Backlog only, not an approved new runtime contract or claim of functionality.

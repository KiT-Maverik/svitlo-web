# Optional Resource Download Preferences

**Status:** Proposed — not implemented by this document.
**Area:** onboarding

## Goal

Let learners choose optional heavy offline resource categories without hiding necessary lesson content.

## Intended scope

- Offer explicit category controls for audio, video, images, interactive models and other large media.
- Show size estimates and whether a resource is essential for a selected lesson.
- An optional resource can be omitted only if the selected offline learning promise remains fulfilled by a pedagogically equivalent alternative.
- Support later downloading missing categories, inspecting availability and storage limits.

## Open decisions and constraints

Define mandatory versus optional bundles and alternative modes per resource and per locale; no silent content removal.

**Implementation note:** This is a product-backlog specification, not approval to edit runtime contracts, add dependencies or claim the feature exists.

# User Settings & Quick Settings

**Status:** Proposed — not implemented by this document.
**Area:** onboarding

## Goal

Build full settings screen and compact quick-settings panel.

## Intended scope

- Provide settings for preferred/secondary language, accessibility modes, offline packages, audio/media, notifications and profile scope where supported.
- Propose a configurable quick-access panel based on frequently needed tasks.
- Respect child/parent ownership and separate per-profile versus account-level preferences.

## Open decisions and constraints

Determine which settings actually warrant quick access and their defaults.

**Implementation note:** This is a product-backlog specification, not approval to edit runtime contracts, add dependencies or claim the feature exists.

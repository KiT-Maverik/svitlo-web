# Teacher-Built Control Assessments

**Status:** Proposed — not implemented by this document.
**Area:** assessment

## Goal

Let teachers build a control/test from selected Lessons and modules.

## Intended scope

- A control is a composed Quiz configuration referencing explicitly chosen Questions and/or approved generated question policies.
- Choose source modules, lessons, topics, skills and permitted variants.
- Preserve origin IDs, test validity, student audience, language and version for later review.

## Open decisions and constraints

Specify authoring UI, permissions, scoring ownership and stable published snapshot.

**Implementation note:** This is a product-backlog specification, not approval to edit runtime contracts, add dependencies or claim the feature exists.

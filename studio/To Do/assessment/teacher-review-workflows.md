# Automatic vs Teacher-Reviewed Assessment Results

**Status:** Proposed — not implemented by this document.
**Area:** assessment

## Goal

Support two modes of grading/release for teacher-created control assessments.

## Intended scope

- Mode A: automatic evaluation and immediate result availability to learner.
- Mode B: teacher manually reviews submitted answers and explicitly releases feedback/result afterward.
- Record grading states and audit history; protect the student's work during review and regrade.
- Quiz config must eventually distinguish evaluation and result release; don't invent current fields.

## Open decisions and constraints

Resolve rubric ownership, partial points, regrade, feedback edit and offline result delivery.

**Implementation note:** This is a product-backlog specification, not approval to edit runtime contracts, add dependencies or claim the feature exists.

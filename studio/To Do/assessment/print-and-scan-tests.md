# Printable Tests & Scannable Answer Sheets

**Status:** Proposed — not implemented by this document.
**Area:** assessment

## Goal

Offer optional paper delivery and mobile capture of exam results.

## Intended scope

- Generate printable test variants with secure attempt/test version identifier and clearly marked answer entry region.
- Allow phone-photo submission; recognize attempt ID, answer blocks and optical marks before automatic draft result.
- Provide uncertainty review and human correction instead of silently grading illegible marks.
- Support offline printing and delayed upload, student privacy and anti-impersonation measures.

## Open decisions and constraints

Select printed layout/QR, computer vision accuracy targets and supported question formats.

**Implementation note:** This is a product-backlog specification, not approval to edit runtime contracts, add dependencies or claim the feature exists.

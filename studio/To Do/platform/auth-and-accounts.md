# Authentication, Account Backend & Identity

**Status:** Proposed — not implemented by this document.
**Area:** platform

## Goal

Plan a real authentication/account service and privacy-safe account lifecycle.

## Intended scope

- Establish serious backend/service ownership beyond placeholder backend workspace.
- Separate authentication, authorisation, account, learner profile and content permissions.
- Support children, parents, teachers, consent and data export/deletion according to law/region.
- Maintain offline learning/progress without forcing a live authentication roundtrip for an already downloaded lesson.

## Open decisions and constraints

Select identity provider, hosting, security model, child protection and regional compliance.

**Implementation note:** This is a product-backlog specification, not approval to edit runtime contracts, add dependencies or claim the feature exists.

# Multiple Learner Profiles per Family Account

**Status:** Proposed — not implemented by this document.
**Area:** platform

## Goal

Support several children under one family login.

## Intended scope

- Allow separate profiles with independent history, notes, quizzes, skills and language/device preferences.
- Prevent one child's results from leaking into or overwriting another's state.
- Support switching within one account with appropriate parental authorization.
- Handle offline profiles and later sync/conflict resolution.

## Open decisions and constraints

Decide profile ownership, age range, device policy, local encryption, migration and account limits.

**Implementation note:** This is a product-backlog specification, not approval to edit runtime contracts, add dependencies or claim the feature exists.

# Parent Subaccount & Child Controls

**Status:** Proposed — not implemented by this document.
**Area:** platform

## Goal

Design a parent role capable of managing linked learners.

## Intended scope

- Define supervised access, subscription/notification preferences, learner progress views and privacy boundaries.
- Support multiple children; ensure controls do not grant unintended data access.
- Avoid implying that a parent account or feature is currently implemented.

## Open decisions and constraints

Choose age-specific restrictions, guardian verification, legal permissions and notification ethics.

**Implementation note:** This is a product-backlog specification, not approval to edit runtime contracts, add dependencies or claim the feature exists.

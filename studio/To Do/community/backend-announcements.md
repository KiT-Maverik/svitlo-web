# Backend Announcement Types & Suppression

**Status:** Proposed — not implemented by this document.
**Area:** community

## Goal

Deliver user-facing notices, calls to action and product updates.

## Intended scope

- Support typed announcements from backend: updates, reminders, calls to action, other approved categories.
- Render as modal/page/banner based on importance, with action vs dismiss choices.
- Allow 'not this type for a while' or 'never show this type' per user/profile.
- Apply frequency caps, security filtering, offline queueing and consent constraints.

## Open decisions and constraints

Define event targeting, suppression semantics, urgent notice exceptions and security review.

**Implementation note:** Backlog only, not an approved new runtime contract or claim of functionality.
